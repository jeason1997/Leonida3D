# Leonida 3D — Unity native port

Unity **6000.3.18f1** + URP. Native port of the offline web build (`../web`).

## Open / run

1. Unity Hub → Add → select this `unity/` folder.
2. Open `Assets/Scenes/Leonida.unity`.
3. Press **Play**.

The editor reads shared assets from `../web/site/assets` when
`Assets/StreamingAssets/leonida/assets` is absent.

Before building a player, sync them:

```powershell
powershell -ExecutionPolicy Bypass -File tools/sync-assets.ps1
```

Then use `Leonida > Build Scene + Windows Player` (output `Build/Windows/Leonida.exe`).

## Controls

| Key | Action |
|---|---|
| W A S D | move |
| Q / E | down / up |
| right mouse drag | look |
| Shift | boost |
| Ctrl | slow |

`LeonidaWorld > Chunk Radius` controls how many 2048 m tiles load (2 = 25 tiles,
5 = all 110). Higher radius is slower and uses much more memory.

Optional test arguments for `Leonida.exe`:

```
-camx -3500 -camy 40 -camz -1700 -lookx -3300 -looky 30 -lookz -1900
-screenshot path.png
```

## Implemented

- manifest, 110 far-terrain chunks (464,750 vertices)
- near terrain: 8 m tiles with the web build's `color_*.jpg` aerial textures
- glTFast runtime loading of GLB city tiles, with the glTF→Unity X mirror corrected
- material mapping by mesh/primitive: walls, roofs, roads, sidewalks, water
- facade shader (procedural window grid, wall/glass colours, night windows)
- water shader (scrolling normals, Fresnel, sun specular, fog)
- procedural skybox (gradient/atmosphere/sun)
- ACES tonemapping + bloom + colour adjustments post stack
- vegetation: 21 GLB variants, `veg/inst_*.bin` parsing, instanced trees/shrubs/grass
- roof details: `details/det_*.bin` mesh + vertex colours
- 60 km ocean, directional light, shadows, fog
- fly camera, loading HUD, scene + Windows player build pipeline

## Not yet

  procedural window grid, not the exact stylised facade)
- roof detail shader (currently a vertex-colour unlit material)
- roof props `roads/props.json`
- baked AO texture path (`ao_*.webp`)
- far vegetation billboards / impostor atlas
- UI (minimap/full map/admin panel/start menu) — deliberately paused
- walk, car, plane
- Android / iOS export

## Data layout

Shared assets are stored once in `../web/site/assets`;
`Assets/StreamingAssets/leonida/assets` is generated by `tools/sync-assets.ps1`
and git-ignored.

`Reference/js/` is the original web JavaScript, for porting reference only.
