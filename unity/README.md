# Leonida 3D — Unity native port

Unity **6000.3.18f1** + URP. This is the native port of the offline web build (`../web`).

## Open / run

1. Unity Hub → Add → select this `unity/` folder.
2. Open `Assets/Scenes/Leonida.unity`.
3. Press **Play**.

The editor reads the shared assets from `../web/site/assets` automatically when
`Assets/StreamingAssets/leonida/assets` is absent.

Before building a player, sync the assets into StreamingAssets:

```powershell
powershell -ExecutionPolicy Bypass -File tools/sync-assets.ps1
```

Then use `Leonida > Build Scene + Windows Player` (output `Build/Windows/Leonida.exe`).

## Controls

| Key | Action |
|---|---|
| W A S D | move |
| Q / E | down / up |
| right mouse drag | look |
| Shift | boost |
| Ctrl | slow |

`LeonidaWorld > Chunk Radius` controls how many 2048 m tiles load (2 = 25 tiles,
5 = all 110). Higher radius is slower and uses much more memory.

## Current status

Implemented:

- manifest, 110 far-terrain chunks (464,750 vertices)
- glTFast runtime loading of GLB city tiles
- material mapping: walls, roofs, roads, sidewalks, water
- 60 km ocean, directional light, shadows, fog
- fly camera, loading HUD
- scene + Windows player build pipeline

Not yet:

- facade/window, water, sky, AO shaders from the web version
- vegetation and roof details
- minimap / big map / admin UI / teleports
- walk, car, plane
- Android / iOS export

The web version is the visual reference; the Unity port is being brought to parity step by step.

## Data layout

Shared assets are stored once in `../web/site/assets`; `Assets/StreamingAssets/leonida/assets`
is generated by `tools/sync-assets.ps1` and git-ignored.

`Reference/js/` is the original web JavaScript, for porting reference only.
