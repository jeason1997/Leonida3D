LEONIDA 3D · 离线版
====================

双击 “Leonida 3D.exe” 即可打开，完全不需要联网。

包含什么
--------
Leonida 3D.exe   启动器（自带本地网页服务，约 9 MB）
site\            完整离线镜像，约 237 MB / 509 个文件
                 城市区块、地形、植被、贴图、小地图、车辆、地标等都在这里
使用说明.txt     本文件

第一次打开
----------
启动器会调用系统自带的 Microsoft Edge，以“应用窗口”方式打开（没有地址栏和标签页），
所以看起来就是一个独立 App。第一次会创建一个专用浏览器配置，需要几秒；之后启动会
直接读本地文件和缓存，基本秒开。

关闭应用窗口后，后台的本地服务会自动退出，不会残留进程。

移动 / 备份
-----------
整个 “Leonida 3D” 文件夹可以随意复制到其他磁盘、移动硬盘或另一台 Windows 电脑。
注意：不能只复制 exe，site 文件夹必须和 exe 放在同一层。

快捷方式
--------
右键 “Leonida 3D.exe” → 发送到 → 桌面快捷方式，
或者右键 → 固定到任务栏 / 开始屏幕。图标是棕榈日落。

· 地图数据版权归 leonidastate3d.com / YANIS 社区所有，本离线包仅供个人离线使用，
  请勿用于商业用途或再次分发。
· 原站更新后，本地版本不会自动跟着更新；需要新地图时重新制作 site 镜像即可。
· 如果 Windows 首次运行提示“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”。
  这是因为 exe 没有数字签名，属于正常提示。
· 如果 Edge 被卸载或找不到，启动器会退回默认浏览器打开（仍可离线使用，只是有地址栏）。
